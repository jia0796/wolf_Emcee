### A. 板子配置、分類與既有房規（AWB-01、AWB-21、AWB-35～36）

- **只新增一張 12 人特殊板子**：「12 人 覺醒狼美人／覺醒獵人」；不取代既有「狼美人／騎士」或普通獵人板子。選單沿用原有「特殊板子」分類、卡片及選擇介面，其他板子排列／分類不變。
- **4 狼**：普通狼人 ×3、**覺醒狼美人 ×1**；**4 神**：預言家、女巫、守衛、**覺醒獵人**各 ×1；**4 民**：平民 ×4。勝利、角色陣營、一般主持與共通房規沿用現有 12 人板子規則。
- 新板子**不繼承**普通狼美人的兩個專屬房規「女巫毒殺觸發殉情」、「最後一狼可殉情」；覺醒狼美人的**替死**依本板已定案條件自動計算，不套用普通狼美人的殉情觸發開關。原普通狼美人板子及其房規不變。
- **固定夜序**：守衛 → 狼人共同狼刀（覺醒狼美人參與）→ 覺醒狼美人獨立魅惑 → 女巫 → 預言家 → 覺醒獵人 → 天亮。不得另增夜間實際巡獵操作。
- 覺醒狼美人固定三句主持字幕，**逐字**：①「覺醒狼美人請睜眼」②「選擇你今晚要魅惑的對象」③「覺醒狼美人請閉眼」。包含冷卻、替死能力已消耗或角色已出局的非終局夜晚，字幕仍完整出現；禁止不合法選擇，不得因此略過字幕。
- 覺醒獵人固定三句主持字幕，**逐字**：①「覺醒獵人請睜眼」②「今晚的巡獵手勢」③「覺醒獵人請閉眼」。存活時依法定資格於夜間操作區顯示 **👍／👎 手勢**，**不是當晚操作巡獵**；已出局則仍保留三句字幕，操作區顯示「覺醒獵人已出局」，不顯示手勢。普通獵人夜間也使用 👍／👎 操作區手勢，但維持普通獵人原字幕「今晚的開槍手勢」與原本開槍資格；任何角色遇**正式終局**即停止後續夜序。

### B. 覺醒狼美人：魅惑、冷卻、自動替死（AWB-02～08、AWB-20、AWB-28～29）

1. **狼人身分**：與普通狼人共同睜眼、參與基本狼刀；**不能自刀、不能自爆**。獨立魅惑階段可選**其他任一存活玩家**，包含其他普通狼人、神職、平民；**不能選自己或已出局者**，也可合法空過。
2. **一晚魅惑、下一晚冷卻**：只有實際成功使用魅惑的夜晚才使**下一晚不可魅惑**；冷卻後再恢復資格。可用之夜主動**空過**不算施放、不觸發下一晚冷卻。示例：第 1 晚魅惑 → 第 2 晚冷卻 → 第 3 晚可用但空過 → 第 4 晚魅惑 → 第 5 晚冷卻。沿用原狼美人的目標操作、提交、上一／下一步，不另發明提交時機。
3. **連結有效期**：魅惑不永久跨夜；作用於**施放當晚及其對應死亡結算、翌日白天的相關觸發**（包括放逐及合法白天巡獵），至**下一夜開始**失效。保留與 AWB-09～11、AWB-26 相容的白天替死判定；不可誤在天亮時提前消除有效連結。
4. **自動替死**：覺醒狼美人因合法致命事件原本將出局且當前連結有效、替死尚未用過時，由當晚被魅惑者替其實際出局；**不另開法官確認畫面**。狼美人存活，技能**每局僅能成功替死一次**；成功後**永久不能再魅惑**（仍保留固定夜間字幕，操作鎖定）。未觸發成功替死不得提前消耗一次性能力。
5. **已受其他傷害的被連玩家**：若被魅惑者當晚已因其他合法原因死亡，同批仍可被指定作為覺醒狼美人的替死對象；狼美人存活、能力消耗，**該目標只計一次實際死亡**，不虛構第二名死者。原傷害（例如「遭女巫毒殺」）與「狼美人替死」維持**兩格獨立事件**；原始事件與實際死亡去重分開處理，不能合併、覆蓋或丟失其中一筆。（AWB-05～06）**後續裁定：同一夜較早批次已死仍可替死；白天觸發時目標已死則不可。替死不受守衛／解藥阻擋。**
6. **同批與不同批**：覺醒狼美人若在**同一夜間正式結算批次**遭多筆一般合法致命傷害，成功替死**一次便統一抵擋該批全部傷害**，被連者只出局一次；每筆原傷害仍獨立記錄（AWB-28）。若**另一獨立批次**再次使狼美人受到合法致命傷害，因能力已用盡而**正常出局**；無整晚無敵或第二次替死（AWB-29）。覺醒獵人特殊命中優先依下節 AWB-09～11，不受「一般傷害同批」文字改寫。
7. **遺言**：替死本身**不額外授予遺言**；第一晚所有實際死亡者（含純替死）依原首夜規則各有一次遺言，原本已具資格者不重複給予。**後續裁定：放逐或槍殺轉移給替死者時，沿致命來源繼承該次遺言資格，僅實際死者說一次。**勝負與原生死亡事件優先序維持既有引擎。

### C. 覺醒獵人：巡獵資格、方向與特殊命中（AWB-09～19、AWB-23～24）

1. **發動資格**：覺醒獵人若因**狼刀**或**白天正式放逐**而符合原獵人開槍資格，可選方向巡獵或明確選「不巡獵」；**遭女巫毒殺**或**因狼美人替死而出局**，**一律不得巡獵**，與普通獵人禁槍條件一致。不得錯寫為「被毒仍可巡獵」。其他原本不合法的死亡來源亦不能擅自取得資格。
2. **操作位置**：夜間只顯示手勢。符合資格的夜間死亡，在**天亮死亡公告對應的遺言／無遺言死亡頁**操作；白天合法死亡同樣沿用其**原有死亡頁**。與已實作的死亡技能併頁機制相容，**不另做「啟動技能」頁／額外確認頁**。法官選方向後，同頁立即預覽引擎算出的**最後實際命中座號**；按**下一步**才正式提交巡獵死亡及復盤紀錄。
3. **方向選擇（不可預設）**：從獵人自己**相鄰左／右座號**選擇起掃座位，按對應方向自動掃描並循環，不要求法官逐席點選。例如 6 號：「從5號」走 5→4→3…→1→12→11…；「從7號」走 7→8→9…→12→1…。按鈕依後續要求簡化為**「從X號」**，選定後同列顯示「巡獵 → X號」及提示中的最終命中座號。必須**主動選一側**或「不巡獵」；未選任何選項時**下一步禁用**，不得自動放棄。掃描不重複處理獵人自身。**夜間／白天巡獵依原死亡來源判定，不依操作當時畫面時間。**
4. **一般命中**：掃描時跳過**存活好人與所有已出局座號**（不重複建立死亡）；命中該方向**第一名存活普通狼人**即擊殺。遇到**沒有有效連結**的覺醒狼美人，正常命中並擊殺。這是法官流程工具，**不設翻牌／不翻牌 UI 規格**。
5. **白天遇有有效魅惑的覺醒狼美人**：不直接射殺狼美人，而是沿同方向跳過中途其他狼人，尋至**被魅惑目標的座位**；若該目標仍存活，**不論陣營**直接命中該目標、狼美人存活，並**視為成功使用一次替死**，從此永久失去魅惑（AWB-09、AWB-11）。**若被魅惑者先前已出局**，改為**直接命中狼美人本人**，絕不能再殺已死玩家（AWB-10）。
6. **夜間遇有有效魅惑的覺醒狼美人**：合法夜間巡獵掃描命中時**直接擊殺狼美人**，不轉移給被魅惑者；此分支**不會**讓女巫毒死的覺醒獵人變成合法可巡獵（AWB-09、AWB-24）。
7. **槍殺遺言／隊列**：巡獵造成的死亡採**原生獵人開槍遺言規則**（首夜死者皆有遺言；白天被放逐獵人的巡獵目標依原規則有遺言）（AWB-17）。多人同批死亡維持原始排隊順序；處理覺醒獵人並正式確認槍殺後，**將新巡獵死亡插入尚待處理隊列之前**，處理完新死亡才返回原隊列；不建立獵人專屬優先隊列（AWB-19）。
8. **終局優先**：先按引擎既有批次合法完成死亡與勝負判定；已正式終局不再額外開啟巡獵、遺言、公告或其他下一步。不得新增不存在的「巡獵一圈未命中」流程；若狼人已全部出局，應依勝負規則終局，而非繼續要求巡獵（原 AWB-30 取消）。

### D. 主持公告、投票、復盤及技能素材（AWB-06、AWB-14、AWB-26～27、AWB-32）

- **白天替死不改原票型**：被放逐選中者及全部原始投票、統計／紀錄完整保留；替死造成的**實際出局者另記、另顯示**，不把原放逐結果改寫成替死者。例如投票選中 3 號覺醒狼美人、8 號替死，**原放逐仍為 3 號，實際死亡為 8 號**；勝負／存活狀態按實際死亡計算（AWB-26）。
- **主持主字幕只公告實際出局者**：沿用現有死亡／遺言字幕，不新增「狼美人替死」專用主持台詞；技能原因放在**法官資訊及復盤**。例如實際死亡者為 8 號，主字幕沿用「8號玩家出局」對應原流程（AWB-27）。
- **技能 SVG 直接重用、不改圖檔**：覺醒狼美人魅惑 → `public/skills/icon-charm.svg`；覺醒狼美人**替死** → 原狼美人**殉情視覺圖** `public/skills/icon-heartbreak.svg`；覺醒獵人巡獵 → 原獵人槍圖 `public/skills/icon-gun.svg`。只是**圖示重用**，不可誤把替死當普通狼美人殉情、把巡獵當普通獵人自由選目標。圖示標籤與實際記錄按新技能語意處理。
- **復盤沿用舊格式**：不新增不同版型、特殊展示頁或人工結算頁；沿用 `public/recap.js` 等現有事件、肖像、技能 SVG 與時間線。記錄真實魅惑目標、替死原因／消耗、各筆原始傷害及單次實際死亡、巡獵方向／最終目標與放棄，保留當時必要快照；覺醒獵人復盤圖示上方不顯示巡獵起點／命中的小字，但原始方向、結果與目標記錄完整保留；白天原投票與替死兩者並存，AWB-06 雙格事件不得合併。存檔／上一步／刷新恢復／舊局不得重複執行或杜撰事件。

### E. 圖鑑正式文字（AWB-34；逐字使用）

> 夜晚與其他狼人共同睜眼並參與狼刀，不能自刀或自爆。夜晚可魅惑一名其他存活玩家，當自己即將出局時，由當晚被魅惑的玩家替死。發動魅惑後下一晚無法再次魅惑。一旦觸發替死，魅惑能力將永久失效。

### 2. 啟動、重整及恢復判定矩陣

| 使用情境 | 是否播放 |

**啟動判定實作注意**：

- 不得以全域單一「已播放」旗標阻止其他真正的新分頁播放；也不得因跨分頁共用存檔而錯誤觸發動畫。啟動判定不應修改或遷移遊戲的存檔資料。

### 1. 共通規則

- **基本接刀資格只在每晚開始時計算**：前一白天最後原始狼人出局，下一晚才能接刀；當晚夜間中途全滅不追補狼刀。機械狼、假面、尋香魅影於本板所有原普通狼人出局且自身存活時接刀。**轉化者**須原普通狼人及覺醒石像鬼全部出局，且已成功轉化、本人存活、符合原 joinNight 加入時機，才接刀；轉化者自己不列入原始狼人存活數。**轉化必定成功，不存在「轉化失敗」狀態。**
- 四種角色的基本狼刀與機械狼學狼人取得的額外狼刀**均可自刀、可空刀**；可以跟原本技能同晚使用，也可指定相同座號；保留各自技能限制。機械狼兩把刀可同晚各刀一次，同人亦可，兩次獨立傷害／使用紀錄。
- **角色「請閉眼」畫面按下一步，才正式提交**狼刀與技能結果；此前可自由選擇、取消、修改。閉眼主字幕不變，僅有狼刀資格時顯示小字目標或空刀摘要（機械狼基本／額外分開）。空刀可直接下一步，不建假攻擊。
- **所有原普通狼人出局後，原狼人階段仍完整保留「狼人請睜眼」→「選擇你們今晚要襲擊的對象」→「狼人請閉眼」**，座位環照常顯示但不能選刀，也不能改空刀或覆蓋已提交刀口；接刀特殊角色在此不再操作，不重複產生狼刀紀錄。真正終局仍立即停止後續字幕。同時仍有原普通狼人時原狼人選刀流程不變。不得因轉化者被統計為狼人而使原狼人階段重複操作。
- 四種角色即使死亡，後續未終局的夜晚仍照常顯示完整專屬字幕、固定步驟及座位環，但技能與狼刀均不可操作；終局不再入夜。
- **只更換基本狼刀選取的位置，不改結算**：女巫得知基本狼刀刀口（包含自刀），不因機械狼額外狼刀得到第二刀口；守衛、解藥、同守同救、傷害批次、殉情與勝負依原有邏輯。雙刀同人仍為兩筆獨立傷害，一次解藥不自動抵擋兩次。已提交狼刀後該角色當夜死亡，攻擊仍正常結算，不在選刀時提前判出局。
- 上一步、重整與讀取存檔要恢復資格、目標、技能、消耗、刀種分頁及復盤；**修改基本刀口後只清掉與新刀口衝突的解藥等相依資料**，不清守衛、毒藥、額外刀及不相干技能，重算死亡、殉情、勝負與卡片，不產生重複紀錄。必要時升級存檔版本並向下兼容，不補造舊存檔歷史。

### 2. 四個角色夜間流程（維持其他角色順序）

**機械狼／通靈師（10／12 人）**

> 12 人機通字幕另依本手冊 MEC-HUNTER-01 的後續裁定：首夜加固定手勢句，第二晚起獵人閉眼後加三句機械狼獵人手勢；下面原首夜三句僅適用 10 人板。
- 第一晚原位置：**機械狼請睜眼 → 選擇你要學習的對象 → 機械狼請閉眼**；其他首夜階段順序不變。
- 第二晚起順序：守衛 → **機械狼** → 狼人 → 女巫 → 通靈師 → 獵人（12 人）。機械狼固定字幕：**機械狼請睜眼 → 今晚的帶刀狀態 → 選擇你要學習的對象 → 選擇使用技能的對象 → 機械狼請閉眼**。
- 已學習也照念「選擇你要學習的對象」，不能重複學習；無可用主動技能仍照念「選擇使用技能的對象」，小字顯示「本晚無可使用技能」，不影響狼刀切換。
- **基本狼刀**需原普通狼全滅；**額外狼刀**僅在已學習狼人且符合原有額外刀房規／解鎖／使用次數時開放，不因未接基本狼刀而停用。兩刀獨立選人、提交、傷害、消耗和復盤。

**轉化者／覺醒石像鬼（10／12 人）**
- 第一晚維持守衛 → 狼人 → 覺醒石像鬼 → 女巫 → 預言家 → 守墓人 → 獵人（12 人）→ 轉化者確認身分；轉化者必定成功，沿用原職技能。
- **第二晚起新增固定獨立階段，放在守衛與狼人之間**：守衛 → 轉化者 → 狼人 → 女巫 → 預言家 → 守墓人 → 獵人（12 人）。字幕固定：**轉化者請睜眼 → 今晚的帶刀狀態 → 轉化者請閉眼**。只在帶刀狀態頁面操作狼刀，無額外右側切換；未具資格或已死可直接跳下一步，字幕不消失。
- 復盤及座位身分沿用「轉化者（原職簡稱）」。

**假面／舞者（12 人）**
- 首夜維持舞者 → 假面（認身分）→ 狼人 → 女巫 → 預言家 → 白痴。
- 第二晚起：舞者 → **假面** → 狼人 → 女巫 → 預言家。假面字幕固定：**假面請睜眼 → 今晚的帶刀狀態 → 請選擇你要查驗的對象 → 獨立「-」查驗結果畫面 → 請選擇你要賦予面具的對象 → 假面請閉眼**。查驗結果仍另外顯示，不可用狼刀介面覆蓋。

**尋香魅影／覺醒預言家（10／12 人）**
- 首夜維持守衛 → 狼人 → 尋香魅影（固定認出其中一位狼隊友、綁定）→ 女巫 → 覺醒預言家 → 獵人（12 人）。
- 第二晚起：守衛 → **尋香魅影** → 狼人 → 女巫 → 覺醒預言家 → 獵人（12 人）；字幕固定：**尋香魅影請睜眼 → 今晚的帶刀狀態 → 請選擇你要綁定的對象 → 尋香魅影請閉眼**。
- 綁定永久消耗後仍念「請選擇你要綁定的對象」，下方小字「綁定能力已使用」、禁止再次綁定；取得接刀資格時狼刀仍可用，原綁定／殉情規則不動。

### B. 查驗、接刀與共通規則（SK-02～SK-08、SK-10、SK-14～SK-15）

- **查驗**（SK-02、SK-03、SK-05、SK-07）：完全比照現有通靈師，存活且可正常行動時每晚**必須**選一名**存活**玩家，不可空過；可查自己、可連續不同夜晚重複查同一人，得知**具體職業**而非陣營。結果卡只顯示「X 號玩家・職業」，不另加狼人／好人陣營字樣；新「石像鬼」顯示石像鬼，不得混寫成「覺醒石像鬼」。接刀後依然每晚查驗；查驗及狼刀可以同晚選同一號。沒有查驗結果時不可製造虛構結果。
- **接刀**（SK-01、SK-04、SK-05、SK-06）：普通狼人全部出局後，**存活石像鬼從下一晚**接手**基本狼刀**；資格只在每晚開始時計算，普通狼人若於當夜中途全滅，不在同夜補刀或產生第二刀。取得資格後可攻擊其他存活玩家、**自刀、空刀**；未取得資格不能選刀，普通狼人仍依原普通狼人階段操作，不能多提交一次基本狼刀。
- **帶刀 UI（SK-10、SK-15；沿用機械狼／假面等共通實作）**：第二晚起保留「今晚的帶刀狀態」階段，具有資格時可直接在帶刀頁選刀／空刀；查驗技能階段仍提供「狼刀／技能」切換，兩種操作個別保留，來回切換不清空對方的選擇。切到狼刀時主持**主字幕不變**，小字可沿用「狼刀選擇」。不新增「選擇你今晚要襲擊的對象」或「請選擇今晚要擊殺的玩家」等**石像鬼專用狼刀字幕／獨立攻擊步驟**。在石像鬼「請閉眼」按下一步才正式提交狼刀與技能，回退、刷新後恢復本夜狀態與之前歷史；空刀不製造假攻擊。石像鬼沒有機械狼的額外狼刀。
- **普通狼人原階段**：即使普通狼人全出局，若遊戲尚未終局，保留原普通狼人睜眼、襲擊、閉眼的固定主持字幕與座位環，但不可選擇狼刀，也不得覆蓋石像鬼已選的基本刀口。不得把新石像鬼算成「仍存活的普通狼人」而阻止接刀。
- **石像鬼死亡（SK-08）**：未正式終局時，後續夜晚仍保留石像鬼的既定睜眼、帶刀狀態（適用夜晚）、查驗、結果、閉眼階段；查驗、狼刀鎖定，無新查驗結果，主持可正常下一步。真正終局即停止後續流程。
- **傷害／結果**：沿用現有女巫所知基本刀口、守衛、防護、解藥、毒藥、同守同救、傷害批次、死亡公告、勝負優先序，不改原引擎。原狼人、石像鬼與其他死亡事件依現有引擎統一結算，不得重複結算或以刀口選擇提前判勝。
- **勝負（SK-14）**：新石像鬼與普通狼人同屬狼人陣營，不另有個人勝利條件。普通狼人全滅而石像鬼存活時，狼人陣營並未全滅；石像鬼死亡而普通狼人存活亦然；兩者均出局則依原屠邊／屠城與既有終局判定。不可套用原「覺醒石像鬼轉化者」的勝負機制。
- **復盤（SK-14 選 A）**：保存石像鬼真實職業、每晚查驗目標與**當時**查到的具體職業、每晚接刀資格、實際基本刀口或空刀、自刀、死亡原因、事件次序、存檔與上一步歷史。依使用者後續裁定，復盤不顯示「帶刀狀態」卡，只呈現實際查驗與狼刀事件；接刀資格與空刀狀態仍保留於原存檔／回退資料。人物肖像融入現有復盤卡背景；沿用既有 SVG、標記排列、復盤事件結構。未使用刀時不可捏造命中或出局紀錄。
