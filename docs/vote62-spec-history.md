### 1. 紀錄模式與畫面

- 保留「紀錄票型」按鈕啟動；有同輪草稿時顯示「繼續紀錄票型」及「已紀錄 X/Y 人」。共用一份草稿的「多人投同一位」與「逐人紀錄」兩種模式，切換不遺失資料。
- **多人模式**：頂部顯示目前得票對象的號碼、票數與適用警徽，點一下展開合法候選人清單，選擇後自動收合；下方為合法投票者格。**此模式不設上一位／下一位按鈕**。逐人模式保留上一位／下一位，不循環，末位下一位禁用；依下方最新修訂，逐人模式按「下一位」時若目前玩家未選候選人，須即時記為棄票。兩模式均不因單純切換模式、點選候選人而自動送出正式統計或進入遊戲下一階段。
- 多人候選人清單按座號遞增，每列一人，座號及即時草稿票數分列左右；清單可獨立捲動，每列觸控高度至少44px。候選人被選中只用低彩度紫色邊框／底色，不加勾或「選取中」，有票者不額外標記；現任警長候選人座號旁沿用 App 既有警徽（不加「警長」文字）。票數含既有適用的警長 1.5 權重，格式為「0票」「1票」「1.5票」，整數不補 .0。
- 候選人區固定頂端、投票者區獨立捲動，底部固定「完成統計」，考量 iPhone Safari／PWA 安全區、動態工具列、短螢幕、大字體、巢狀慣性捲動及誤觸。切換**不同**候選人時投票者區回頂端；重點相同候選人不重置。重新開啟同輪草稿恢復上次模式、候選人／投票者及投票者有效捲動位置，無效位置回退合法第一項／頂端；候選人清單每次開啟編輯器時先收合，展開狀態不寫入遊戲存檔。首次進入多人模式預選最小座號合法候選人，但不自動記票。
- 切到逐人模式，優先定位最小座號尚未紀錄合法投票者；若全已紀錄則第一位合法投票者。切回多人模式恢復上次合法候選人，無效時選最小座號合法候選人。逐人模式候選人最多每列三個，已選者紫色／勾，不顯示多餘「目前投給」文字；**逐人未選票直接按「下一位」即標記該玩家棄票**，無須手動選「棄票」，並仍在完成統計時自動處理其餘尚未紀錄者。
- 投票者按座號遞增，不因已投票而重排；不合法投票者不可選。多人模式投票者格：投目前候選人為紫色／勾並標「投X號」；投其他候選人為灰色「投Y號」，仍可點擊直接改票（舊票移除）；未投為「未紀錄」。再次點已投目前候選人的投票者取消該票。格子手機常態四欄，窄螢幕／大字體三欄，必要時維持可觸控尺寸；文字可換行。選票微動畫約 150～200ms，偏好減少動態效果時停用。
- 紀錄中獨立顯示「已紀錄 X/Y 人」：X 為有有效候選人選票的人數（不是加權票數），Y 為合法投票者人數；逐人按「下一位」直接棄票不增加 X，取消選票則減少 X。完成統計按鈕固定僅顯示「完成統計」，不附進度。完成統計後隱藏進度，改顯示正式結果摘要；按「修改票型」再恢復進度。

### 1A. 逐人紀錄操作與版面最新修訂（2026-10-18；已實作並部署）

> **本段為已確認的新規格，優先於本節較早描述的「跳過未紀錄者、完成統計時才作棄票」。此修訂已實作並部署，驗證紀錄見第 6 節。** 僅更動**一般放逐投票的逐人紀錄模式**；警長選舉、警長 PK、放逐 PK 原本的操作和介面完全不變。

1. **目前投票者號碼框**：在模式切換下方，用醒目的**獨立外框**顯示目前玩家座號（例如框內「4號」），明確區分「目前由誰投票」和下方「可投給誰」的候選人格；不再單獨用一行一般文字顯示目前座號。
2. **移除手動棄票選項**：逐人模式的候選人方格只顯示當輪合法候選人，**不顯示「棄票」格或按鈕**。一般放逐投票多人模式亦不得提供手動選「棄票」得票對象；完成統計仍負責補齊尚未紀錄者。
3. **「下一位」即時棄票**：逐人模式若目前玩家**未選任何候選人**，按「下一位」就**立即在同輪草稿記為棄票**，再切換至下一位；如已選候選人，維持原有選票並前進。這是逐人模式的紀錄行為，**不是正式完成統計或遊戲階段的「下一步」**。不能因點擊座號或模式切換就記為棄票。
4. **棄票可回頭修正**：使用「上一位」回看已跳過玩家時，保留其草稿棄票狀態；若改為選擇合法候選人，該位原草稿棄票必須被新選票取代，不可同時計為投票與棄票。模式切換、關閉續編與重新整理應維持同輪草稿的一致性，不重複加票或棄票。
5. **底部操作位置**：逐人模式從上到下為「模式切換 → 目前投票者獨立號碼框 → 候選人格 → 底部上一位／下一位 → 完成統計 → 更多操作」。將「上一位／下一位」從候選人格上方移到下方，且放在「完成統計」之前；兩鍵並列、保持既有邊界禁用規則。考慮 iPhone Safari／PWA 安全區及短螢幕捲動，避免底部控制被遮住。
6. **完成統計補棄票不變**：逐人模式「下一位」即時記下的棄票，及**仍未經過或未記錄**的合法投票者，在正式「完成統計」時統一算入棄票結果；不得重複計算。依既有 VOTE-41，全員棄票正式結果顯示「本輪無有效票」，不修改放逐／PK 規則。
7. **驗收新增情境**：未投直接下一位、已投下一位、返回棄票者改投、取消後再次下一位、在多人／逐人間切換、關閉／重整續編、最後一位按「完成統計」、全員棄票、票數加權與進度 X/Y、修改票型及上一步回退。確認棄票候選按鈕不再出現在一般放逐投票兩模式中；不影響警長與所有 PK 投票。

### 2. 草稿、提交、手動覆蓋與復盤

- 按 × 關閉紀錄視窗，保留**同一局同一投票輪次**尚未提交草稿，不產生正式票型／復盤。草稿在重整、Safari／PWA 背景恢復後仍可續編，不跨輪次、PK 或新局；不能覆蓋已正式提交的資料。小型「清空紀錄」需兩次確認，只清未提交草稿；既有「放棄票型紀錄」行為不擅改。
- 「完成統計」直接正式提交，不另彈確認；逐人操作已明確跳過者保留棄票狀態，其餘尚未紀錄的合法投票者也在此時自動視為棄票，保留棄票人數及座號，但不計入候選人票數。提交後依既有投票／同票規則預選最高票結果，**不自動按下一步**。第一次完成統計不顯示 toast。
- 完成統計後，按「修改票型」開啟已填妥的編輯草稿；按 × 時原正式紀錄不變，只有再次「完成統計」才替換正式票型，並重新計算、預選最新最高票結果。重新提交後只短暫顯示「票型已更新」（約 2 秒），不加其他文案。
- **復盤票型顯示資格由按「下一步」當下的最終選擇決定**：未完成統計而退出、在主畫面手動選擇放逐對象者，復盤不顯示票型；已完成統計但最終改選非系統預選結果者，復盤也不顯示本輪票型。若下一步前改回最新正式統計的預選結果，仍顯示票型。改選不同時，在「下一步」上方顯示小字「目前選擇與票型統計結果不同，繼續後不記錄本輪票型復盤。」；改回預選結果則消失，不阻止操作、不彈窗。只控制復盤呈現，不刪除原始紀錄或回退歷史；實際放逐選擇與原有 PK／同票規則不變。

### 3. 正式結果卡

- 展開預設顯示候選人票數與投票者座號、棄票人數及座號；標題摘要「已投票 X 人 · 棄票 Y 人」。可收合，收合後保留各有票候選人的座號／票數、最高票視覺標示、棄票人數、摘要及右上角小型「修改票型」按鈕；隱藏投票者及棄票座號。
- 候選人單欄依**加權票數降序**，同票依座號升序；座號用中等粗體、票數用一般字重同列顯示，如「1號 3票」，下一行小字「投票：4、6、8號」，完整自然換行不截斷。最高票候選人以低彩度紫色框／底色標示，多位同票各自標示，**不加「最高票」「同票」「平票」文字**。投票者座號旁的警徽沿用既有樣式，不額外標字；1.5 權重僅於原有適用情況生效。
- 一般放逐及放逐 PK 的結果／復盤候選人清單不顯示 0 票候選人（不影響投票資格或遊戲資料）；警長選舉／警長 PK 的 0 票候選人只於底部摘要「未獲票：5、7、9號」，收合仍可見，**其既有操作介面維持不變**。
- 棄票區低對比置於候選人卡下方。全員棄票時顯示「已投票 0 人 · 棄票 X 人」及「本輪無有效票」；展開列出棄票座號，收合隱藏座號，不顯示 0 票候選人卡；**不自行定義全棄票後放逐／PK 判定**，沿用既有流程。
- 結果卡展開／收合採約 180～220ms 高度／淡入淡出，減少動態效果時即時切換，避免頁面跳動。
