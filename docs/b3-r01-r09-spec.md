### R01｜主持操作區排版（不改座位欄數）
- 現況參考 \`public/index.html\` \`#host .host-center\`、\`.judge-box\`、\`#hint\`、\`#operationCard\`、\`#actions\`；\`public/app.js\` \`renderOperation()\` 與接手狼刀 \`#knifeToggle\`。
- 樣式上統一成同一可讀玻璃區：提示小字 → 技能 SVG＋名稱＋次操作小按鈕（按鈕優先同列，擠不下自然折行）→ 已選目標／結果；不保留割裂的第二層獨立操作底板。
- JS 必要時僅調整呈現 DOM／CSS，不更動 \`action()\` 原本的 click、disabled、執行順序與狀態資料；按鈕實際點擊區至少44px。
- **座位左右雙欄 \`#left\` 1–6、\`#right\` 7–12 保留**。短螢幕允許內容區內捲動，不遮住最後按鈕。

### R02｜警上、退水及投票選中
- 以 1px 冰晶細框替換現有過粗候選亮白框；警上、退水與投票選中保留文字標籤及明確區別；只在對應狀態顯示，不以永久標籤佔位。
- 保留警徽、技能、角色名、死亡／禁止投票／PK 狀態及原可選／不可選；不得以裝飾覆蓋原本受限制的玩家或觸控。

### R03｜一般放逐的票型編輯器
- 只對 \`public/index.html\` \`#exileVoteDialog\` 及 \`public/vote-ui.js\` 普通放逐編輯器（後半 \`ordinary\` 實作）作**外觀與排列**修整；\`#voteDialog\` 的警長和全部 PK 維持原介面。
- 「多人投同一位」頂部顯示「① 選擇得票對象」，單一大型橫列顯示 N號＋當前得票，點擊展開可捲動條列號碼（選好關閉），底下「② 勾選投票者」為清楚不同形狀的玩家小方格，冰藍已選框＋勾。進度及操作提示位於投票者區。
- 保留原 \`details/summary\` 開闔、dropdown 最末列可直接點、現在票數、警徽、復盤及草稿記錄；不可恢復舊的棄票按鈕或替換原編輯資料結構。
- 「逐人紀錄」不顯示棄票選項，未投票按下一位才記棄票；底部上一位／下一位及完成統計保留。不可改 \`setBallot\`、\`submitVote\`、\`tallyVotes\`、投票資格與結果預選的判定。
- \`#voteDialog\`、所有警長／警長 PK／放逐 PK 的模式、資格、空過與記錄流程不得套用新版選票方格或排版。

### R04｜發言計時器
- 限改原計時 dialog CSS/呈現，設定模式：−10秒｜透明冰霧滾輪＋上下冰藍細刻度｜+10秒；下方開始（冰藍主鍵）、重置（冰霧次鍵）、較小重設。
- 開始後原動畫過渡為無滾輪純倒數數字畫面：暫停／繼續＋重置，較小重設；保留原倒數、完成、重置回設定時間、重設預設時間、關閉與恢復效果。不得改時間運算、狀態機或存檔。

### R05｜透明度 Token（玻璃背景不透明度）
| 類型 | Alpha | 說明 |
|---|---:|---|
| 首頁操作按鈕 | 0.20 | 非常透明，保留液態反光、邊框及文字對比 |
| 玩家座位卡 | 0.48 | 角色／技能／選中態清晰，背景可透出 |
| 主持資訊區 | 0.68 | 原字幕與操作提示保有閱讀對比 |
| 復盤事件＋最終身分卡 | 0.65 | 取代舊厚重灰黑感，事件可讀 |

- \`rgba\`／\`rgb(... / alpha)\` 只能施於底色、不可設 \`opacity\` 在整張卡。日夜不同背景時只加局部文字遮罩；Safari 不支援 blur 用深色安全降級；高密度票型／計時對話框優先可讀。
- \`public/b3.css\` 及既有 CSS 層級需檢查衝突，避免某些按鈕因 \`#actions\` 特例而遺留金色。

### R06｜復盤事件與最終身分卡
- \`public/recap.js\` 產生的真實事件資訊及 \`public/recap.css\`／\`public/b3.css\` 視覺修正：事件卡、身分卡同用 65% 冰霧玻璃，不做整張金、粉、黑灰大底。陣營色只顯示於人物名稱及已核准原圖示；**26 技能 SVG 原檔與顏色不變**。
- 發動者、目標的原人物插畫直接融合事件卡左右背景，沒有獨立小框；單目標、雙目標、無目標、空過、投票、PK 與歷史資料 fallback 都維持。
- 復盤順序與勝負原因、月光時間軸、最終身分雙欄、狼人陣營在前／好人神職再平民、感染／轉化／存亡內容維持。

### R07｜防雙擊誤放大，不禁止正常縮放
- 以 \`touch-action: manipulation\` 等對互動區友善的非阻塞 CSS 阻止按鈕、座位、投票與列表連續點擊導致雙擊放大；保留 \`pinch-zoom\`、iOS 慣性捲動、Tab／焦點、輔助功能。不要設 viewport \`user-scalable=no\` 或 \`maximum-scale=1\`，不全域阻止 \`touchmove\`／\`gesturestart\`。
- 實體 Safari／iOS PWA／Android 實測並記錄，不能保證所有作業系統都完全阻止手勢縮放。

### R08｜角色金框與人物對齊
- 圖鑑原 \`.role-card\` 與翻卡 \`.preview-front\` 移除新增的藍色外框，只留下**圖片本身原黑底與原金框**；不增加新的 CSS 仿金框覆蓋原圖。
- 統一原圖比例、金框在容器內的位置，再逐角色以 \`object-position\`／容器內位移／顯示尺寸（非破壞方式）檢查人物視覺中心；不得 stretch、裁斷人物或金框。
- 原始圖片及翻卡行為（正反面、技能內容、關閉與滾動）全保留；無法只靠 CSS 校正的圖記錄為素材例外，待另行授權處理。

- \`public/engine.js\` 的 \`phaseOf()\`、夜間步驟、字幕、復盤、存檔與所有遊戲邏輯**禁止更動**。優先在 \`public/app.js\` 到 \`public/b3-ui.js\` 的呈現層給 \`confirm\` 專屬背景及顯示字串。
